# Downloads

SABnzbd behind Gluetun, with an isolated VPN namespace, firewall kill switch,
encrypted upstream DNS, and a Home Assistant status/setup panel.

Supports amd64 and aarch64. Requires NET_ADMIN and `/dev/net/tun`; host networking,
Docker access, and Home Assistant management API access are not requested.

Read [configuration and operation](DOCS.md) before starting a download.
